🔍 Les 3 signaux d'alerte qu'il fallait repérer

  • Un vrai Wi-Fi public ne demande jamais votre mot de passe : un hôtel, un café ou un aéroport peut vous demander un e-mail ou un code reçu par SMS, jamais le mot de passe de votre messagerie ou de votre compte Google.
  • L'adresse du site (URL) ne correspondait pas : même en cliquant sur « Google » ou « Facebook », la barre d'adresse ne pointait pas vers le site officiel.
  • Le piège du « Wi-Fi jumeau » (Evil Twin) : n'importe quel individu malveillant peut créer un point d'accès nommé WIFI_GRATUIT en 2 minutes avec un simple smartphone ou un boîtier de poche.

🛡️ Les bons réflexes en déplacement

  • Privilégiez la 4G / 5G : votre connexion mobile personnelle est bien plus sûre qu'un Wi-Fi public ouvert.
  • Ne réutilisez jamais le même mot de passe sur plusieurs sites (sinon un seul piège compromet tous vos comptes).
  • Activez la double authentification (2FA) : même si un pirate vole votre mot de passe, il restera bloqué sans le code de validation.
  • Utilisez un VPN fiable si vous devez absolument vous connecter à un Wi-Fi public.
